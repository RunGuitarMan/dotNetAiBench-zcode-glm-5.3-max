## 1. Модель предметной области

### 1.1 Участники (роли)

| Участник | Описание | Ключевые ограничения |
|---|---|---|
| Компания | Клиент установки; всё принадлежит компании | Изоляция данных между компаниями (B02) |
| Сотрудник | Профиль: `masterId` (уникален в компании, не передаётся другому), признак активности, теги аудитории; без учётных данных | Не подтверждает своё выполнение, не начисляет, не отменяет (B03) |
| Владелец кампании | Действующий сотрудник, назначенный администратором; полномочие на конкретную кампанию | Не увеличивает бюджет, не читает полный кошелёк участника (B03) |
| Администратор компании | Управляет профилями, ресурсами, кампаниями, владельцами, бюджетами, разрешениями | Только своя компания; не обходит бизнес-ограничения, в т.ч. нехватку средств (B03) |
| Корпоративная интеграция (доверенный источник) | Передаёт прогресс / начисляет / списывает — только по явно выданным разрешениям | Остальные полномочия не возникают «по факту доверия» (B04) |
| Система покупок | Зарегистрированная админином корпоративная система; видит свою историю операций, не весь кошелёк | Инициирует и возвращает траты только по разрешению (B04, B23, B27) |

Роль «владелец» — надстройка над сотрудником; блокировка сотрудника прекращает и его полномочия владельца (B05).

### 1.2 Сущности

| Сущность | Существенные атрибуты | Принадлежность / состояния |
|---|---|---|
| Профиль сотрудника | `masterId`, активен/заблокирован, теги | Компания; Активен ↔ Заблокирован |
| Кошелёк | Балансы по каждому ресурсу (целые, ≥ 0) | 1:1 с профилем, создаётся при создании профиля; не удаляется, не меняет владельца |
| Ресурс | Код (уникален в компании без учёта регистра, неизменяем), название | Компания; Активен → Архивный (необратимо) |
| Сезон | Календарный год в поясе компании (Europe/Tallinn) | Один на компанию в момент времени |
| Кампания | Код (уникален компания+сезон), название, описание, владелец, сезон, сроки, аудитория (3 набора тегов) | Компания; Черновик → Опубликована → Архив |
| Стрим | Код (уникален в кампании), название; общий накопительный прогресс и вехи | Кампании; наследует аудиторию кампании; архивируем |
| Задание | Код (уникален в стриме), название, описание действия, цель > 0, периодичность, очки стрима ≥ 0, список ресурсных наград | Стриму; архивируемо |
| Позиция награды | Ресурс (один раз в списке) + сумма > 0; ресурс входит в кампанию | Заданию |
| Бюджет | Остаток на пару «кампания × ресурс»; = выделения − начисления + отмены | Только администратор выделяет/увеличивает |
| Веха | Порог > 0 + достижение; выдаёт только достижения | Стриму |
| Достижение | Код (уникален в компании), название, описание | Компания; выдаётся ≤ 1 раза за сезон сотруднику |
| Челлендж | Один стрим кампании, интервал внутри сроков кампании; задаётся до публикации | Кампании |
| Разрешение интеграции | Источник × (прогресс по кампании / начисление ресурсов из бюджета / списание ресурсов для системы покупок) | Выдаёт/отзывает администратор |
| Система покупок | Зарегистрированная система + принимаемые ресурсы | Управляет администратор |
| Операция | Событие прогресса, выделение бюджета, ручное начисление, списание, отмена; номер источника; результат проведена/отклонена с причиной | Компания; неизменяема |
| Событие прогресса | Сотрудник, задание, переданное увеличение > 0, номер события (уникален компания+источник), переданное и зачтённое увеличение, момент принятия | От доверенного источника |
| Выписка | Интервал, ресурс (один/все), состояние, зафиксированный набор данных | Заказчик: сотрудник (свой кошелёк) или администратор |

### 1.3 Существенные связи

| Связь | Кратность | Смысл |
|---|---|---|
| Компания → сотрудники, ресурсы, кампании, достижения, системы покупок, разрешения | 1:N | Изоляция по B02; межфирменные связи запрещены |
| Профиль сотрудника → кошелёк | 1:1 | Ровно один кошелёк с создания профиля |
| Кошелёк → балансы | 1:N | По одному балансу на ресурс компании; один ресурс из разных кампаний — один баланс |
| Кампания → стрим → задание | 1:N → 1:N | Иерархия содержимого; коды уникальны на своём уровне |
| Задание → позиции награды → ресурс | 1:N → N:1 | Все позиции выдаются атомарно |
| Кампания × ресурс → бюджет | 1:1 на пару | Отдельный бюджет на каждую пару |
| Стрим → веха → достижение | 1:N → N:1 | Порог очков стрима выдаёт достижение |
| Кампания → челлендж → стрим | N:1 → N:1 | Интервал внутри сроков кампании; задаётся до публикации |
| Операция → исходная операция | N:1 | Только для полной отмены; у оригинала ≤ 1 успешная отмена |
| Выписка → заказчик | N:1 | Доступ только заказчику с действующими правами |

| Влияние отмены награды | Не отзывается | Не отзывается | Средства возвращаются в бюджеты | Баланс уменьшается на пакет | Результат не меняется (B33.4) |
| На что влияет | Завершение; счёт челленджа (через зачтённое) | Вехи → достижения | Бюджеты и кошелёк | Траты и выписка | Места (1, 1, 3), порядок по masterId |

Достижения — отдельное понятие: выдаются из вех по очкам стрима, ≤ 1 раза за сезон на сотрудника, сохраняют историю сезонов (B29–B30).
